# Project Management System

A comprehensive Project Management System designed to help organizations efficiently manage projects, campaigns, initiatives, tasks, resources, and reports from a centralized platform.

## 🚀 Features

### Project Management

* Create and manage projects
* Project templates
* Project status tracking
* Project timeline management
* Budget and estimated hours tracking

### Campaign & Initiative Management

* Create campaigns within projects
* Create initiatives under campaigns
* Track campaign progress
* Monitor initiative performance

### Task Management

* Create, assign, and track tasks
* Task priorities and statuses
* Due date management
* Task dependencies
* Task comments and activity logs

### User & Role Management

* User registration and authentication
* Role-based access control
* Tenant management
* Team member assignment

### My Work Dashboard

* Personalized task dashboard
* Task filtering by:

  * Project
  * Status
  * Start Date
  * End Date
  * Assignee

### Reports & Analytics

* Project progress reports
* Resource utilization reports
* Task completion analytics
* Dashboard insights

### Notifications

* Email notifications
* Task assignment alerts
* Status update notifications

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/project-management-system.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

## 🔑 Environment Variables

Create a `.env` file:

```env
PORT=5000
DB_HOST=localhost
DB_PORT=3306
DB_NAME=project_management
DB_USER=root
DB_PASSWORD=password
JWT_SECRET=your_secret_key
```
